# Spike: beginner flight feel

**Status:** code complete, automated tests green, Windows build OK. Hands-on test with the real DualSense still pending.

## Run it

- **Editor:** open the project in Unity 6000.3.2f1, open `Assets/_Project/Scenes/FlightTest.unity`, press Play.
- **Build:** `Builds/Windows/DroneSimulator.exe`
- **Regenerate scene:** menu `DroneSim → Rebuild Flight Test Scene` (the scene is generated by `SceneBuilder.cs`; don't hand-edit it).
- **New build:** menu `DroneSim → Build Windows`.

## Controls

| Action | DualSense (Mode 2) | Keyboard |
|---|---|---|
| Climb / descend | Left stick ↑ / ↓ | W / S |
| Yaw left / right | Left stick ← / → | A / D |
| Forward / back | Right stick ↑ / ↓ | ↑ / ↓ |
| Bank left / right | Right stick ← / → | ← / → |
| Sport mode on / off | R1 | Left Shift |
| Camera chase / FPV | Triangle | C |
| Pause menu (continue / reset / quit) | Options | Esc |
| Reset to start pad | via pause menu | R |
| Debug overlay | Create | F1 |

Releasing all sticks → the drone levels out, brakes vertically and holds altitude (in both modes).

## Flight model (angle mode)

- Stick → target tilt (max 30°), PD controller to reach it.
- Yaw stick → target yaw rate (100°/s).
- Throttle → target vertical speed (+3 / −2 m/s). Centred throttle → brake to ~0, then lock altitude.
- Physics at 250 Hz (fixed step), rendering interpolated.
- All numbers live in `Assets/_Project/Settings/DefaultFlightTuning.asset` — edit them in Play mode to tune feel.
- Sport mode uses `SportFlightTuning.asset`: 45° tilt, 170°/s yaw, +6 / −4 m/s vertical, top speed ≈ 28 m/s (~100 km/h).

## Known limits / findings

- A virtual DualSense HID device ignores the test fixture's synthetic stick events, so stick mapping is tested
  on a generic `Gamepad` (the provider reads the `Gamepad` base class, so the code path is the same). The real
  Bluetooth DualSense must be checked by hand on the debug overlay.
- Altitude hold originally latched the moment throttle was released, causing overshoot and spring-back after a
  climb. It now brakes to near-zero vertical speed first, then latches.
- When the game window loses focus, the Input System resets devices → neutral input → hover. Intended.
